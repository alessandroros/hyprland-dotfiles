# hyprland-dotfiles

Le mie configurazioni custom per Hyprland (via Omarchy).

## Struttura

- `hypr/` — configurazione Hyprland (`~/.config/hypr`): binding, monitor, look & feel, input, autostart.
- `omarchy/` — configurazione Omarchy (`~/.config/omarchy`): branding, hook, plugin, temi, shell.

## Installazione

```sh
git clone https://github.com/<tuo-utente>/hyprland-dotfiles.git
cp -a hyprland-dotfiles/hypr/. ~/.config/hypr/
cp -a hyprland-dotfiles/omarchy/. ~/.config/omarchy/
```
